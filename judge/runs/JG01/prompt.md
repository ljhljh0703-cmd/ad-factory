## 기준표
## 1. 광고에 넣을 것

vault 조사 다섯 묶음에서 사람들이 반응한 것만 골랐다. 영상 하나에 유형 하나.

조사 묶음: 숏폼 후킹 카드(S1) · 공유·입소문 카드(S2) · 광고·영상 정예 카드 · 게임 광고 소재 카드(U1) · 게임 광고 성공 사례(C8)와 성공 사례 종합 · 젤리 패닉 몰입 연구(10-08).

### 1-4. 세계관 도입부 조건

게임에는 아기 쿠키와 위협 5종이 있다(아기 쿠키는 클래식에서 조각 20번째부터, 디펜스는 처음부터 나오고, 아기가 든 줄을 지우면 구출, 까마귀가 아기 옆에서 터지면 게임 오버). 젤리 마을 이야기는 게임에 없어서 도입부는 광고에만 있는 그림책 장면으로 분명히 구분한다(영국 광고심의기구: 게임 화면이 아닌 장면은 그렇다고 알아보이게).

- 그림은 웹 ChatGPT로 뽑은 그림책 그림 여러 장을 편집해서 쓴다. 게임 화면과 헷갈리지 않는 그림체로.
- 도입부는 그림 4장 이내. 그다음 컷부터 실제 플레이다.
- 넘어가는 지점이 보여야 한다: 그림책 페이지가 넘어가고 「실제 게임 화면」 자막.
- 도입부의 위협은 게임에 있는 5종(균열·시럽·굳은설탕·초코슬라임·도둑까마귀)만, 아기는 게임 속 아기 쿠키만. 이름과 생김새를 게임에 맞춘다.
- 도입부에 조각을 끌어 놓는 장면처럼 조작을 그리지 않는다.
- 실제 플레이 구간은 1-2를 다 지킨다. 넘어간 뒤 첫 실제 컷이 위기 장면이다(아기 쿠키 옆 까마귀 예고 등). 도입부에서 아기에게 일어난 일은 게임 규칙 안의 일만(까마귀가 아기를 물고 가는 장면처럼 게임에 없는 결과는 그리지 않음).

### 1-3. 쓰지 말 것 (조사에서 반응이 나빴거나 걸린 것)

- 게임 앞부분에 없는 장면(C8 반례 Playrix·C8 반복 1)
- 가짜로 아깝게 지는 연출(몰입 연구 「근접 실패」 · U1-03 1번)
- 공유에 보상 걸기(성공 사례 종합 반례 GA-14)

숫자·시험 결과·통계는 광고에 넣지 않는다. 게임 화면에 원래 보이는 점수는 그대로 둔다. 젤리 패닉 근거 장부(J01~J10)는 광고 문구가 사실과 어긋나는지 대조할 때만 쓴다.

### 판정 메모

- R1은 장면 하나라도 걸리면 반려. 「대표 장면이 게임 전체에서 아주 작은 부분」인 경우도 사람 확인으로 올린다(ASA 사례).
- R8: 젤리 패닉 그림은 만화체라 대부분 공개 의무 밖이다. ChatGPT 이미지는 생성 정보가 파일에 들어 있어 채널이 AI 표시를 자동으로 붙일 수 있다. 그 정보를 지우는 것도 반려 사유다.
- 앞부분 장면: 플레이 중 얻는 아이템(롤링핀·색 마카롱)과 2단계(조각 20번째부터)의 아기 쿠키·도둑까마귀는 앞부분으로 본다. 스테이지 후반처럼 끝까지 가야 나오는 장면만 사람 확인.
- 가짜로 아깝게 지는 연출: 편집으로 화면 내용(남은 칸, 위협 위치, 점수)을 바꾼 것, 또는 판 위에서 실제로 두지 않은 수를 둔 것처럼 보여 주는 것. 실제 게임에서 실제로 둔 수로 진 판은 일부러 못 둔 수여도 가짜 연출이 아니다(작가 결정 10-22, 답답한 플레이 유형). 이때 문구는 운영자 목소리로 쓰고, 일반 사용자가 못 둔 것처럼 꾸미면 R6.
- 편집으로 확대·멈춤·표시(화살표, 왼쪽·오른쪽 글자)를 더하는 것은 화면 내용을 바꾸지 않으면 괜찮다.
- 게임 기능을 말하는 문구(「같은 판으로 열려요」 등)는 사실표에 있는 기능만. 공유 버튼은 그림만 보낸다.
- 기계 판정은 금지어 목록과 숫자 대조, 모델 판정은 사유 문장까지, 사람 판정은 작가가 최종. 사람이 뒤집은 판정은 1단계 5번 기록으로 남긴다.



## 이 게임에서 보는 법
기준표 1-1 표의 「젤리 패닉 장면」 칸은 젤리 패닉 예시다. 이 게임은 사실표에서 같은 성격의 장면인지로 본다. 사실표의 「광고에_쓰지_않는_것」이 화면에 있으면 R1로 반려한다.

## 판정하는 법
1. 소재마다 반려 조건 R1~R11 과 통과 조건 G1~G8 을 하나씩 본다. 영상이 아닌 소재(게시글·썸네일·공유 카드·토스 안 문구)는 G2~G7 을 보지 않는다.
2. 위반이면 그 조건 번호, 근거가 된 소재의 구절(그대로 옮김), 사유 문장(무엇이·어디에·어떻게 고칠지)을 적는다. 위반이 아니면 적지 않는다.
3. 다음이면 사람확인을 true 로 하고 이유를 한 줄 적는다: 장면이 게임에 있기는 하지만 게임 전체에서 아주 작은 부분인지 판단이 필요할 때, 연출 강도(폭력·공포)가 넘었는지 갈릴 때, 게임 사실만으로 그 장면이 게임에 있는지 알 수 없을 때. 확실한 위반이 있으면 사람확인 대신 위반을 적는다.
4. 소재가 길거나 짧은 것, 문장이 매끄러운 것은 판정에 넣지 않는다.
