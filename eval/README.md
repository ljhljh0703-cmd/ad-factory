## 쓰는 법

- 소재를 고치거나 추가할 때는 `build_evalset.py` 를 고치고 다시 돌린다. 그다음 `python3 check_evalset.py` 가 「결과: 통과」여야 한다.
- 심사기 규칙을 고치는 동안에는 dev 만 본다. holdout 은 심사기 판을 하나 확정할 때 한 번 돌려 점수만 기록한다. holdout 에서 틀린 소재를 보고 규칙을 고쳤다면 그 소재는 dev 로 옮기고 holdout 에 새 소재를 채운다.
- 반려 조건 R1~R11 은 dev 와 holdout 에 하나 이상씩, 합쳐서 2개 이상 있다.
