## 기준표 1절 (광고에 넣을 것)
## 1. 광고에 넣을 것

vault 조사 다섯 묶음에서 사람들이 반응한 것만 골랐다. 영상 하나에 유형 하나.

조사 묶음: 숏폼 후킹 카드(S1) · 공유·입소문 카드(S2) · 광고·영상 정예 카드 · 게임 광고 소재 카드(U1) · 게임 광고 성공 사례(C8)와 성공 사례 종합 · 젤리 패닉 몰입 연구(10-08).

### 1-1. 영상 유형 (하나 고름)

| 유형 | 젤리 패닉 장면 | 조사 근거 |
|---|---|---|
| 질 뻔하다 뒤집기 (기본, 작가 결정) | 한 칸 남기고 몰린 판 → 한 수로 위협을 막고 줄이 연달아 터짐 | U1-03 · 몰입 연구 「실제로 한 수 차이」 |
| 열린 끝 | 아깝게 진 순간에서 끊고 「너라면 어디 놓음?」 | U1-03 · S1-05 미완결 고리 |
| 선택 순간 | 조각 둘 중 어디에 놓을지 멈춤 → 고른 결과 | U1-04 |
| 손 화면·반응 | 한 손으로 끌어 놓는 손 + 「아 이거 아깝다」 같은 실제 반응 | U1-06 · S1-12 크리에이터 말투 |
| 같은 판 도전 | 끝 화면 「이 판 그대로 해 보기」 | 성공 사례 종합 패턴 3 · S2 자랑할 거리 |
| 세계관 도입 → 실제 플레이 (작가 결정 10-22) | 그림책 그림 몇 장: 젤리 마을에서 태어난 아기 쿠키 → 아기를 노리는 도둑까마귀 → 마을을 덮치는 시럽·균열 → 페이지가 넘어가며 실제 게임 화면, 보드 위 아기 쿠키 옆에 까마귀 예고 → 줄을 지워 아기 구출 | 작가 결정 · 1-4 조건 |

### 1-2. 어느 유형이든 넣을 것

| 넣을 것 | 젤리 패닉에서 | 조사 근거 |
|---|---|---|
| 첫 3초 후킹 하나 | 패턴 깨기(위협 예고가 번쩍) · 질문(「여기서 살 수 있음?」) · 공감 상황(「출근길 한 판」) 중 하나 | S1-02 후킹 유형 · 영상-09 |
| 첫 프레임과 제목이 같은 약속 | 제목에 「한 수로 역전」이면 첫 컷도 그 판 | S1-11 |
| 연쇄 손맛과 효과음 | 평범한 배치는 작게, 연쇄는 크게 터지는 실제 효과음. 지는 장면으로 끝나는 유형(열린 끝·같은 판 도전)은 연쇄가 없어도 됨 | 몰입 연구 「성과에 맞는 손맛」 · S1-10 소리 켬 설계 |
| 지켜야 할 것이 보이기 | 위협 앞에 놓인 「소중한 것」(플레이어 사진)이나 아기 쿠키가 첫 실제 컷에 보임. 실제 게임 화면이면 보이는 것으로 보고, 화면 밖으로 잘린 경우만 걸림 | 몰입 연구 「진화와 애착」 · 광고-06 알아보기 쉬운 캐릭터 |
| 다시 보게 되는 끝 | 마지막 컷이 첫 컷의 위기 장면으로 이어짐 | S1-07 반복 재생 구조 |
| 소리 없이도 읽히는 자막 | 상황 한 줄 자막 | S1-03 |
| 웃음 한 번(선택) | 계정 화자의 말끝 · 개발자 놀리기 | 광고-07 유머 · 성공 사례 종합 「젤리 패닉 2」 화자 카드 |

### 1-4. 세계관 도입부 조건

게임에는 아기 쿠키와 위협 5종이 있다(아기 쿠키는 2단계부터 나오고, 아기가 든 줄을 지우면 구출, 까마귀가 아기 옆에서 터지면 게임 오버). 젤리 마을 이야기는 게임에 없어서 도입부는 광고에만 있는 그림책 장면으로 분명히 구분한다(영국 광고심의기구: 게임 화면이 아닌 장면은 그렇다고 알아보이게).

- 그림은 웹 ChatGPT로 뽑은 그림책 그림 여러 장을 편집해서 쓴다. 게임 화면과 헷갈리지 않는 그림체로.
- 도입부는 그림 4장 이내. 그다음 컷부터 실제 플레이다.
- 넘어가는 지점이 보여야 한다: 그림책 페이지가 넘어가고 「실제 게임 화면」 자막.
- 도입부의 위협은 게임에 있는 5종(균열·시럽·굳은설탕·초코슬라임·도둑까마귀)만, 아기는 게임 속 아기 쿠키만. 이름과 생김새를 게임에 맞춘다.
- 도입부에 조각을 끌어 놓는 장면처럼 조작을 그리지 않는다.
- 실제 플레이 구간은 1-2를 다 지킨다. 넘어간 뒤 첫 실제 컷이 위기 장면이다(아기 쿠키 옆 까마귀 예고 등). 도입부에서 아기에게 일어난 일은 게임 규칙 안의 일만(까마귀가 아기를 물고 가는 장면처럼 게임에 없는 결과는 그리지 않음).

### 1-3. 쓰지 말 것 (조사에서 반응이 나빴거나 걸린 것)

- 게임 앞부분에 없는 장면(C8 반례 Playrix·C8 반복 1)
- 가짜로 아깝게 지는 연출(몰입 연구 「근접 실패」 · U1-03 1번)
- 공유에 보상 걸기(성공 사례 종합 반례 GA-14)

숫자·시험 결과·통계는 광고에 넣지 않는다. 게임 화면에 원래 보이는 점수는 그대로 둔다. 젤리 패닉 근거 장부(J01~J10)는 광고 문구가 사실과 어긋나는지 대조할 때만 쓴다.

## 기준표 2·3절 (통과 조건과 반려 조건)
## 2. 통과 조건 (좋은 광고)

전부 만족해야 통과. 판정 칸: 기계 = 문자열·규격 검사, 모델 = AI 심사기 판단, 사람 = 작가 확인.

| 번호 | 조건 | 확인하는 법 | 판정 | 근거 |
|---|---|---|---|---|
| G1 | 광고에 나오는 장면·조작·모드가 전부 실제 빌드에 있다 | 대본의 컷마다 「게임 안 위치」 칸이 채워졌는지. 이미지는 실제 화면 캡처와 나란히 대조 | 모델 + 사람 | 게임산업법 제34조 제1항 제1호, U1-02 |
| G2 | 첫 2~3초 안에 위기 장면이나 고르는 순간이 실제 게임 화면으로 나온다. 질 뻔하다 뒤집기 유형은 끝나기 전에 뒤집힌다. 세계관 도입 유형은 첫 컷이 도입부 그림이고, 넘어간 뒤 첫 실제 컷이 위기 장면이며, 1-4를 지킨다 | 대본 첫 컷이 실제 위기 화면인지(세계관 유형은 도입부 그림 수와 넘어가는 자막), 뒤집는 수가 실제로 가능한 수인지 | 모델 + 사람 | U1-01 · U1-03 · 작가 결정 10-22 |
| G3 | 게임 이름이 앞쪽에 한 번 보인다 | 첫 5초 안 자막·화면 글자에 「젤리 패닉」 | 기계 | U1-01 |
| G4 | 소리 없이도 내용이 전달된다 | 대사·내레이션마다 자막 줄이 있는지 | 기계 | U1-01 |
| G5 | 끝에 할 일이 하나 있고 링크에 출처 태그가 붙는다 | 끝 컷 행동 유도 문구 1개, 링크에 채널별 태그 | 기계 | 마케팅 지시서 측정 연결 |
| G6 | 세로 화면이다 | 9:16 | 기계 | 세 채널 공통 |
| G7 | 1-1 유형 하나로 만들고 1-2를 다 넣었다 | 대본 머리에 유형 이름 한 개 + 1-2 칸별 체크 | 기계 + 모델 | U1-02 4번 · 1절 |
| G8 | 문구에 숫자·통계·시험 결과·순위·인원·평점이 없다. 화면 속 점수, 장면을 말하는 「한 칸」「한 수」는 괜찮음 | 문구에서 숫자 찾기 | 기계 | 작가 지시 10-22 |

## 3. 반려 조건

하나라도 걸리면 반려. 사유 문장은 「무엇이 · 어디에 · 어떻게 고칠지」 순서로 쓴다.

| 번호 | 반려 조건 | 사유 문장 예 | 판정 | 출처 |
|---|---|---|---|---|
| R1 | 게임에 없는 장면·조작·모드·그래픽을 게임 화면처럼 보여 준다. 「실제와 다를 수 있음」 작은 글씨를 붙여도 반려. 세계관 도입부가 1-4를 어기면 반려 | 「3번 컷의 보스전은 게임에 없습니다. 디펜스 모드 위협 장면으로 바꾸세요.」 | 모델 + 사람 | 게임산업법 제34조 제1항 제1호 · 표시광고법 제3조 · 영국 광고심의기구(ASA) 게임 광고 점검 사례 |
| R2 | 근거 없는 최상급·순위·숫자(「1위」「최고」「100만 명」「평점 4.9」) | 「‘전국 1위 퍼즐’은 근거가 없습니다. 지우세요.」 | 기계 + 모델 | 표시광고법 제3조·제5조 · 마케팅 지시서 §2 |
| R3 | 다른 게임과 비교해 깎아내린다 | 「‘○○보다 재밌는’은 비교 근거가 없습니다. 비교를 빼세요.」 | 기계 + 모델 | 표시광고법 제3조(부당 비교·비방) |
| R4 | 경품·현금·보상을 걸어 사행심을 부른다, 또는 공유에 보상을 건다 | 「‘공유하면 상품권’은 넣을 수 없습니다. 보상 문구를 지우세요.」 | 기계 + 모델 | 게임산업법 제34조 제1항 제4호 · 작가 결정 10-11(공유 보상 없음) |

## 쓰는 규칙
- 컷마다 「게임_근거」를 채운다. 사실표의 「없는_것」은 쓰지 않는다. 「조금_뒤에_나오는_것」을 쓰면 녹화_메모에 몇 단계 장면인지 적는다.
- 자막 첫 줄 또는 두 번째 줄 안에 「젤리 패닉」을 넣는다.
- 숫자·순위·평점·시험 결과를 쓰지 않는다. 「한 칸」「한 수」 같은 장면 묘사는 된다.
- 운영자 계정 목소리로 쓴다. 지어낸 사용자 후기, AI 실사 인물, 유명 음원은 쓰지 않는다.
- 세계관 유형은 1-4 조건을 지키고, 그림_요청문은 그림책 그림체(부드러운 색연필·수채 느낌)로 게임 화면과 다르게 요청한다. 아기 쿠키·도둑까마귀·시럽·균열 생김새는 「게임 속 모습과 같은 색과 모양」이라고 적는다. 글자는 그림에 넣지 않는다.
- 같은 유형 안에서도 첫 3초 후킹(패턴 깨기·질문·공감 상황)과 쓰는 위협을 서로 다르게 고른다.
